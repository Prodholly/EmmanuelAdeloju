Refresher 8 projects My own directed refresh of core AI and ML algorithms, rebuilt from scratch to see what frameworks do under the hood.

From ml-foundations, a 115-day curriculum. Each build has its own code, tests, runnable example, README and research log.

  • Day 1

    DataLoader

    A minimal, typed DataLoader built from scratch, with batching, seeded shuffling, drop-last and a pluggable collate function.

    Pythongenerators
    README
  • Day 2

    Linear algebra for ML

    Matrix multiply, softmax and cross-entropy written as plain loops, rebuilt with einsum, then benchmarked against NumPy.

    NumPyeinsum
    README
  • Day 3

    Scientific data explorer

    A command-line tool that profiles any CSV or TSV file, reporting each column's type, missing values, distinct values and summary statistics.

    PythonCLI
    README
  • Day 4

    Data structures and complexity

    Typed utility functions for everyday ML jobs, each with an explicit contract, edge-case handling, complexity analysis and tests.

    Pythonpytest
    README
  • Day 5

    NumPy shapes and broadcasting

    Shape inspection, reshaping, axis reductions and broadcasting, with a loop-versus-NumPy benchmark and animated figures.

    NumPy
    README
  • Day 6

    Gradient checking

    A finite-difference gradient checker that verifies the softmax and cross-entropy gradient to 1e-8, plus vectorization speed curves.

    README

    Probability, statistics and regularized models

    MLE, MAP, Bayes and information theory from scratch, used to build linear and logistic regression and to run three pre-registered experiments.
